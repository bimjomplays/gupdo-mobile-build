# gupdo-mobile-build

Build-only copy of a small personal iPhone app (SwiftUI, iOS 26). GitHub Actions builds it on a hosted Mac: simulator
tests and screenshots (artifacts `report`, `screenshots`), an unsigned IPA on full runs (artifact `GupDo-ipa`) and a
TestFlight upload for internal testing on release runs. Development happens elsewhere; not maintained for anyone
else, and issues or pull requests aren't looked at.
